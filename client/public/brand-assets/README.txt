Specter Brand Logos
====================

This archive contains three Specter logo variants:

- specter-ghost-mascot.png
  The full-color mascot logo with no outline.

- specter-ghost-outline-thick.svg
  The SVG mascot variant with thicker lines for uses where a stronger outline
  is helpful.

- specter-logo.png
  The standard Specter logo used across the website.

The variants use different line treatments. Some have thicker outlines, while
others use a lighter or no outline. Choose the version that remains clear at
the size and on the background where it is used.

Please keep the proportions and colors unchanged when using the logos.
